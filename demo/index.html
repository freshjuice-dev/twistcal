TwistCal

Lightweight, zero-dependency "Add to Calendar" web component. Shadow DOM. Apache-2.0.

Web component (attributes)

Declarative triggers (custom buttons)

Programmatic (import)

JSON-in-script (rich data)

Timezone-pinned (Oslo event, Miami visitor)

How it works

<script type="module" src="../src/twistcal.js"></script>

<!-- Web component -->
<twist-cal title="My Event" start="2026-01-15T10:00:00" end="2026-01-15T11:00:00">
</twist-cal>

<!-- Custom trigger -->
<button data-twistcal data-twistcal-action="google"
  data-twistcal-title="My Event"
  data-twistcal-start="2026-01-15T10:00:00"
  data-twistcal-end="2026-01-15T11:00:00">Add to Google</button>
